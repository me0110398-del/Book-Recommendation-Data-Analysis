# Book-Recommendation-Data-Analysis
##  Project Overview
This project analyzes book datasets to understand user ratings, book popularity, and user behavior using Python.

##  Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

##  Dataset
The project uses three datasets:
- Books.csv
- Users.csv
- Ratings.csv

##  Project Workflow
- Data Loading
- Data Cleaning
- Data Merging
- Statistical Analysis
- Data Visualization

##  Visualizations
- Top 10 Authors
- Distribution of Users' Ages
- Top 5 Authors
- Age vs Book Rating
- Distribution of Book Ratings
